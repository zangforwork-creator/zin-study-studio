# Marketing course sources

These are external learning options, separate from Zin's university course/book catalog. Five entries are stored in `dist/data/online-courses.json`; their official sources were checked on 17 November 2026. Provider pages control availability, pricing and delivery. Opening a source does not enroll or pay for a course.

Reference-image durations are not treated as facts. The website uses verified metadata above, not the pictured approximate durations. Course thumbnails are decorative, code-authored laptop illustrations with provider-name labels; they are not claimed to be official course photography, endorsements or performance charts. No new image download, third-party account connection or checkout was added.

Search combines course title/provider/description. Provider and Online only filters work together; AIM is excluded from Online only. Global search can find library books or curated external courses. Validation rejects unsupported source origins, executable links and duplicate IDs. A failed catalog load shows a retry path while Bookshelf, exams and documents remain usable.
