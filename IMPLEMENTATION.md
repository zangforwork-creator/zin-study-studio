# Initial release

Acceptance: no invented GPA or mastery; six pending grades remain null; accounting and mathematics remain in the transcript; theme, attempts, notes and review dates survive reload; repeated result submissions are idempotent; document versions retain learning history; scanned/unreadable sections show warnings; mobile has no horizontal overflow; both themes and keyboard controls work. Private hosting only.
